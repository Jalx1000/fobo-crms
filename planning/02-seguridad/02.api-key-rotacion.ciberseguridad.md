## Objetivo

Verificar y documentar que todas las credenciales de ShareMeData están correctamente gestionadas en el entorno de producción (Easypanel). Asegurar que ningún secreto esté expuesto en el repositorio.

## Checklist

### 1. Revisión del repositorio git

```bash
# Buscar valores de API key en el historial git
git log --all -p | grep -i "sharemedata\|smd\|gamma\|apikey" | grep -v "^--\|^commit\|^Author\|^Date"

# Verificar que .env no está trackeado
git ls-files .env
# Resultado esperado: vacío (no trackeado)

# Verificar .gitignore
grep "^\.env" .gitignore
```

**Acciones si se encuentra el key en el historial:**
- Rotar el API key con SMD inmediatamente
- Usar `git filter-repo` para limpiar el historial (coordinar con el equipo)

### 2. Variables de entorno en producción (Easypanel)

Verificar que en el contenedor activo existan y sean correctas:

```bash
docker exec $(docker ps --format "{{.Names}}" | grep "odontoking-crm" | head -1) \
  php artisan tinker --execute="
    echo 'API_KEY set: '.(config('services.sharemedata.api_key') ? 'SÍ' : 'NO').PHP_EOL;
    echo 'PATIENTS_URL: '.config('services.sharemedata.patients_url', 'NO CONFIGURADO').PHP_EOL;
    echo 'WEBHOOK_SECRET set: '.(config('services.sharemedata.webhook_secret') ? 'SÍ' : 'NO').PHP_EOL;
    echo 'APP_ENV: '.app()->environment().PHP_EOL;
    echo 'SSL verify deshabilitado: '.(app()->environment(['local','testing']) ? 'SÍ (local/testing)' : 'NO (producción)').PHP_EOL;
  "
```

Resultados esperados:
- `API_KEY set: SÍ`
- `PATIENTS_URL: https://gamma.sharemedata.com/api`
- `WEBHOOK_SECRET set: SÍ`
- `APP_ENV: production`
- `SSL verify deshabilitado: NO (producción)`

### 3. Actualizar `.env.example`

El `.env.example` debe tener todos los placeholders de SMD:

```env
# ShareMeData Integration
SHAREMEDATA_API_KEY=your-api-key-here
SHAREMEDATA_BASE_URL=https://gamma.sharemedata.com/api/calendar
SHAREMEDATA_PATIENTS_URL=https://gamma.sharemedata.com/api
SHAREMEDATA_WEBHOOK_SECRET=generate-with-openssl-rand-hex-32
```
