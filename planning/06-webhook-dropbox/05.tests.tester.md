## Helper: firma válida

```php
function dropboxSignature(string $body): string
{
    return hash_hmac('sha256', $body, config('smd.dropbox.app_secret'));
}
```

---

## Test 1 — Handshake GET responde el challenge

```php
it('responde el challenge de verificacion de Dropbox', function () {
    $response = $this->get('/api/webhooks/dropbox?challenge=test-challenge-abc123');

    $response->assertStatus(200);
    $response->assertHeader('Content-Type', 'text/plain; charset=UTF-8');
    $response->assertSee('test-challenge-abc123');
});
```

Este test verifica que el handshake funciona antes de que Dropbox lo pruebe en producción.

## Test 2 — Firma inválida devuelve 403

```php
it('rechaza POST con firma invalida y devuelve 403', function () {
    $body = json_encode(['list_folder' => ['accounts' => ['dbid:abc']]]);

    $response = $this->withHeaders([
            'X-Dropbox-Signature' => 'firma_invalida_que_no_coincide',
            'Content-Type'        => 'application/json',
        ])
        ->post('/api/webhooks/dropbox', json_decode($body, true));

    $response->assertStatus(403);
});
```

## Test 4 — Notificación válida despacha el job

```php
it('acepta POST con firma valida y despacha ProcessDropboxNotification', function () {
    Queue::fake();

    $payload = json_encode([
        'list_folder' => ['accounts' => ['dbid:AABaSL-a0VmECGvL6TJNWtAeaRRrEkjdTJc']],
        'delta'       => ['users' => [123456789]],
    ]);

    $signature = dropboxSignature($payload);

    $response = $this->withHeaders([
            'X-Dropbox-Signature' => $signature,
            'Content-Type'        => 'application/json',
        ])
        ->call('POST', '/api/webhooks/dropbox', [], [], [], [], $payload);

    $response->assertStatus(200);
    Queue::assertPushed(ProcessDropboxNotification::class);
});
```

**Nota importante:** Usar `call()` con el body crudo en lugar de `postJson()` porque `postJson()` re-serializa el array y puede alterar el body (orden de claves, espacios), haciendo que el HMAC calculado en el test no coincida con el calculado en el controlador.

## Test 5 — Job procesa archivos nuevos cuando hay cursor

```php
it('el job descarga y procesa archivos nuevos desde el cursor guardado', function () {
    // Arrange: cursor guardado en od_settings
    DB::table('od_settings')->insert([
        'key'   => 'dropbox_cursor',
        'value' => 'cursor-previo-fake',
    ]);

    $jsonPayload = [
        '_id'         => 'ext-id-webhook-001',
        'startDate'   => '2026-05-21T10:00:00.000Z',
        'endDate'     => '2026-05-21T10:30:00.000Z',
        'status'      => '',
        'archived'    => false,
        'summary'     => 'Limpieza',
        'attendances' => [[
            '_id'      => 'patient-001',
            'name'     => 'Ana',
            'lastName' => 'García',
            'phone'    => '70000001',
        ]],
        'owner' => [
            '_id'      => 'doctor-unique-001',
            'name'     => 'Dr. López',
            'lastName' => 'Pérez',
        ],
    ];

    $mockDropbox = Mockery::mock(DropboxService::class);
    $mockDropbox->shouldReceive('listChanges')
        ->with('cursor-previo-fake')
        ->andReturn([
            'entries' => [[
                '.tag'       => 'file',
                'name'       => 'event-2026-05-21-001.json',
                'path_lower' => '/smd-events/2026-05-21/event-001.json',
            ]],
            'cursor' => 'cursor-nuevo-fake',
        ]);

    $mockDropbox->shouldReceive('downloadJson')
        ->with('/smd-events/2026-05-21/event-001.json')
        ->andReturn($jsonPayload);

    $this->app->instance(DropboxService::class, $mockDropbox);

    // Act
    (new ProcessDropboxNotification())->handle(
        $mockDropbox,
        app(IncomingAppointmentService::class),
        app(SmdStatusMapper::class),
    );

    // Assert: el evento fue registrado en smd_synced_events
    $this->assertDatabaseHas('smd_synced_events', [
        'external_id' => 'ext-id-webhook-001',
    ]);

    // Assert: el cursor fue actualizado
    $this->assertDatabaseHas('od_settings', [
        'key'   => 'dropbox_cursor',
        'value' => 'cursor-nuevo-fake',
    ]);
});
```

## Test 6 — Job inicializa cursor si no existe

## Test 7 — Job ignora entradas que no son archivos JSON

```php
it('el job ignora carpetas y archivos no-JSON en las entries de Dropbox', function () {
    DB::table('od_settings')->insert(['key' => 'dropbox_cursor', 'value' => 'cursor-xyz']);

    $mockDropbox = Mockery::mock(DropboxService::class);
    $mockDropbox->shouldReceive('listChanges')->andReturn([
        'entries' => [
            ['.tag' => 'folder', 'name' => '2026-05-21', 'path_lower' => '/smd-events/2026-05-21'],
            ['.tag' => 'file',   'name' => 'notes.txt',  'path_lower' => '/smd-events/notes.txt'],
            ['.tag' => 'deleted','name' => 'old.json',   'path_lower' => '/smd-events/old.json'],
        ],
        'cursor' => 'cursor-xyz-2',
    ]);
    $mockDropbox->shouldNotReceive('downloadJson');

    $this->app->instance(DropboxService::class, $mockDropbox);

    (new ProcessDropboxNotification())->handle(
        $mockDropbox,
        app(IncomingAppointmentService::class),
        app(SmdStatusMapper::class),
    );

    // No se crearon eventos
    $this->assertDatabaseCount('smd_synced_events', 0);
});
```

## Consideraciones

- Los tests que usan `DB` necesitan `use RefreshDatabase` o `use DatabaseTransactions`.
- El `DROPBOX_APP_SECRET` debe estar en `.env.testing` para los tests de firma. Usar un valor fake: `DROPBOX_APP_SECRET=test-secret-for-testing`.
- Los tests del job usan mocks de `DropboxService` para no llamar a la API real — igual que el patrón de los tests existentes de `SyncDropboxAppointments`.
