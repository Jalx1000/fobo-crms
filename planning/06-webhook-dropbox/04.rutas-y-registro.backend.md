# Tarea 6.4 — Rutas, registro y comando de inicialización

**Agente asignado:** `backend`
**Fase:** 06 — Webhook de Dropbox
**Complejidad:** Baja
**Tiempo estimado:** 1h
**Dependencias:** Tarea 6.2 (controlador)

---

## Objetivo

Registrar las rutas públicas del webhook, excluirlas de CSRF, crear el comando de inicialización del cursor y verificar la coexistencia con el scheduler.

---

## 1. Registrar la ruta en `routes/api.php`

El webhook de Dropbox sigue el mismo patrón que el webhook de ShareMeData ya registrado en ese archivo. Agregar junto a la ruta existente:

```php
// routes/api.php

use Webkul\Admin\Http\Controllers\DropboxWebhookController;

/**
 * Webhook de Dropbox (handshake + notificaciones)
 */
Route::controller(DropboxWebhookController::class)
    ->prefix('/webhooks/dropbox')
    ->middleware('throttle:120,1')
    ->group(function () {
        Route::get('',  'verify')->name('admin.webhook.dropbox.verify');
        Route::post('', 'handle')->name('admin.webhook.dropbox.handle');
    });
```

### Por qué en `routes/api.php` y no en el ServiceProvider

El webhook de ShareMeData ya está en `routes/api.php` (línea 124), no registrado en el ServiceProvider. Seguir el mismo patrón mantiene consistencia y evita tocar el ServiceProvider.

El grupo `api` de Laravel ya aplica el middleware `throttle:api` por defecto — anulamos con `throttle:120,1` (120 peticiones/minuto) que es más generoso que el 60/1 del SMD webhook, ya que Dropbox puede enviar múltiples notificaciones en ráfaga.

## 2. Excluir del CSRF

Agregar la ruta al array `$except` de `app/Http/Middleware/VerifyCsrfToken.php`:

```php
protected $except = [
    'admin/mail/inbound-parse',
    'admin/web-forms/forms/*',
    'api/webhooks/sharemedata',
    'api/webhooks/dropbox',    // ← agregar
    'api/v1/*',
];
```

La ruta GET de verificación no necesita excepción CSRF (solo el POST), pero incluir el prefijo completo cubre ambos métodos sin riesgo.

## 5. Comando `smd:dropbox-init-cursor`

Útil para inicializar el cursor manualmente antes de activar el webhook, o para resetear el cursor si se corrompe.

```
packages/Webkul/Admin/src/Console/Commands/InitDropboxCursor.php
```

```php
<?php

namespace Webkul\Admin\Console\Commands;

use Illuminate\Console\Command;
use Illuminate\Support\Facades\DB;
use Webkul\Admin\Services\DropboxService;

class InitDropboxCursor extends Command
{
    protected $signature   = 'smd:dropbox-init-cursor {--force : Sobreescribir cursor existente}';
    protected $description = 'Inicializa el cursor de Dropbox para el webhook en tiempo real';

    public function handle(DropboxService $dropbox): int
    {
        $existing = DB::table('od_settings')->where('key', 'dropbox_cursor')->first();

        if ($existing && ! $this->option('force')) {
            $this->warn('Ya existe un cursor. Usa --force para sobreescribir.');
            $this->line('Cursor actual: ' . substr($existing->value, 0, 40) . '...');
            return self::SUCCESS;
        }

        $folder = config('smd.dropbox.appointments_folder', '/smd-events');

        $this->info("Obteniendo cursor inicial para: {$folder}");

        $cursor = $dropbox->getInitialCursor($folder);

        if (! $cursor) {
            $this->error('Error obteniendo el cursor. Verifica DROPBOX_ACCESS_TOKEN.');
            return self::FAILURE;
        }

        DB::table('od_settings')->updateOrInsert(
            ['key' => 'dropbox_cursor'],
            ['value' => $cursor, 'updated_at' => now()]
        );

        $this->info('Cursor guardado correctamente.');
        $this->line('Valor: ' . substr($cursor, 0, 40) . '...');

        return self::SUCCESS;
    }
}
```

Registrar el comando en `AdminServiceProvider::boot()`:

```php
$this->commands([
    SyncDropboxAppointments::class,
    InitDropboxCursor::class,   // ← agregar
]);
```

## 6. Coexistencia con el scheduler

El scheduler actual en `app/Console/Kernel.php`:

```php
$schedule->command('smd:sync-dropbox')->everyFiveMinutes();
```

Opciones post-activación del webhook:

**Opción A (recomendada):** Extender intervalo a 30 minutos
```php
$schedule->command('smd:sync-dropbox')->everyThirtyMinutes();
```

**Opción B:** Desactivar completamente (comentar la línea)

La deduplicación por `external_id` + hash del payload garantiza que si ambos (webhook y scheduler) procesan el mismo archivo, el segundo paso siempre resulte en `$skipped++` sin duplicados en el CRM.

## 7. Orden de deploy

Al hacer el deploy de esta fase, seguir este orden:

1. `php artisan migrate` — crear `od_settings` si no existe
2. `php artisan smd:dropbox-init-cursor` — capturar cursor antes de activar el webhook
3. Agregar `DROPBOX_APP_SECRET` al `.env` en el servidor
4. `php artisan config:clear`
5. Registrar la URL en el Developer Console de Dropbox → el handshake GET ocurre en este momento
6. Verificar logs: `tail -f storage/logs/laravel.log | grep Dropbox`
