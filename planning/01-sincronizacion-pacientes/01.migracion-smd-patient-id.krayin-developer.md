## Objetivo

Agregar la columna `smd_patient_id` a la tabla `persons` para almacenar el identificador del paciente en ShareMeData (`_id` retornado por la API de patients de SMD).

## Contexto

Actualmente el CRM no puede hacer `PATCH /api/patients/{id}` porque no guarda el ID externo del paciente en SMD. Sin esta columna, cada vez que se crea una cita se intenta crear el paciente en SMD sin saber si ya existe, generando duplicados.
