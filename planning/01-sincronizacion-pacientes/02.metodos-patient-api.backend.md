## Objetivo

Añadir tres métodos al `ShareMeDataService` para gestionar pacientes en la API v2 de SMD. Estos métodos permiten buscar, crear y actualizar pacientes en SMD antes de crear una cita.

## Contexto crítico — Base URL diferente

⚠️ Los endpoints de patients usan una base URL **diferente** a la del calendario:

| Tipo | Base URL |
|------|----------|
| Calendario (actual) | `https://gamma.sharemedata.com/api/calendar` |
| Patients (nuevo) | `https://gamma.sharemedata.com/api` |

**Acción previa:** Agregar al `.env` y `config/services.php`:

```env
SHAREMEDATA_PATIENTS_URL=https://gamma.sharemedata.com/api
```

```php
// config/services.php
'sharemedata' => [
    'api_key'        => env('SHAREMEDATA_API_KEY'),
    'base_url'       => env('SHAREMEDATA_BASE_URL', 'https://gamma.sharemedata.com/api/calendar'),
    'patients_url'   => env('SHAREMEDATA_PATIENTS_URL', 'https://gamma.sharemedata.com/api'),
    'webhook_secret' => env('SHAREMEDATA_WEBHOOK_SECRET'),
],
```

### `searchPatient(string $phone): array`

```php
/**
 * Busca un paciente en SMD por número de teléfono.
 * Retorna array de resultados (vacío si no encuentra).
 */
public function searchPatient(string $phone): array
{
    try {
        $response = $this->http()->get("{$this->patientsBaseUrl}/patients", [
            'where'      => 'phone=/' . urlencode($phone) . '/',
            'select'     => '_id,fullName,phone,secondEmail,name.lastName',
            'pageSize'   => 20,
            'pageNumber' => 1,
        ]);

        if ($response->successful()) {
            return $response->json('data') ?? $response->json() ?? [];
        }

        Log::warning('[SMD] searchPatient falló', [
            'phone'    => $phone,
            'status'   => $response->status(),
            'response' => $response->json(),
        ]);

        return [];
    } catch (\Exception $e) {
        Log::error('[SMD] searchPatient excepción: ' . $e->getMessage());
        return [];
    }
}
```

### `createPatient(array $data): array`

```php
/**
 * Crea un nuevo paciente en SMD.
 * Retorna ['success' => bool, 'data' => [...], 'message' => '...']
 *
 * Maneja 400 @error.duplicatePatient como caso especial (no como error fatal).
 */
public function createPatient(array $data): array
{
    try {
        $payload = array_filter([
            'name'        => $data['first_name'] ?? null,
            'lastName'    => $data['last_name']  ?? null,
            'phone'       => $data['phone']       ?? null,
            'birthday'    => $data['birthday']    ?? null,
            'gender'      => $data['gender']      ?? null,
            'personID'    => $data['ci']          ?? null,
            'expedido'    => $data['expedido']    ?? null,
            'secondEmail' => $data['email']       ?? null,
            'nationality' => $data['nationality'] ?? 'BO',
        ], fn($v) => $v !== null);

        if (! empty($data['insurance'])) {
            $payload['extra'] = ['insurance' => (array) $data['insurance']];
        }

        $response = $this->http()
            ->withHeaders(['Content-Type' => 'application/json'])
            ->post("{$this->patientsBaseUrl}/patients/user", $payload);

        if ($response->successful()) {
            return ['success' => true, 'data' => $response->json()];
        }

        $body    = $response->json();
        $message = $body['message'] ?? $response->body();

        // Duplicado no es error fatal — el llamador decide qué hacer
        $isDuplicate = str_contains($message, '@error.duplicatePatient');

        Log::warning('[SMD] createPatient ' . ($isDuplicate ? 'duplicado' : 'falló'), [
            'payload'  => $payload,
            'status'   => $response->status(),
            'response' => $body,
        ]);

        return [
            'success'      => false,
            'duplicate'    => $isDuplicate,
            'message'      => $message,
            'status'       => $response->status(),
        ];
    } catch (\Exception $e) {
        Log::error('[SMD] createPatient excepción: ' . $e->getMessage());
        return ['success' => false, 'message' => $e->getMessage()];
    }
}
```

### `updatePatient(string $smdPatientId, array $data): array`

```php
/**
 * Actualiza datos de un paciente existente en SMD.
 */
public function updatePatient(string $smdPatientId, array $data): array
{
    try {
        $payload = array_filter([
            'name'        => $data['first_name'] ?? null,
            'lastName'    => $data['last_name']  ?? null,
            'phone'       => $data['phone']       ?? null,
            'birthday'    => $data['birthday']    ?? null,
            'personID'    => $data['ci']          ?? null,
            'secondEmail' => $data['email']       ?? null,
        ], fn($v) => $v !== null);

        $response = $this->http()
            ->withHeaders(['Content-Type' => 'application/json'])
            ->patch("{$this->patientsBaseUrl}/patients/{$smdPatientId}", $payload);

        if ($response->successful()) {
            return ['success' => true, 'data' => $response->json()];
        }

        Log::warning('[SMD] updatePatient falló', [
            'smd_patient_id' => $smdPatientId,
            'status'         => $response->status(),
            'response'       => $response->json(),
        ]);

        return ['success' => false, 'status' => $response->status(), 'message' => $response->json('message')];
    } catch (\Exception $e) {
        Log::error('[SMD] updatePatient excepción: ' . $e->getMessage());
        return ['success' => false, 'message' => $e->getMessage()];
    }
}
```

## Criterios de aceptación

- [ ] `searchPatient('77788990')` retorna array (vacío o con resultados)
- [ ] `createPatient([...])` retorna `['success' => true, 'data' => [...]]` en creación exitosa
- [ ] `createPatient([...])` retorna `['success' => false, 'duplicate' => true]` si el paciente ya existe en SMD
- [ ] `updatePatient('abc123', [...])` retorna `['success' => true]`
- [ ] Ningún método lanza excepción sin capturar
- [ ] Los logs de warning incluyen contexto pero NO loguean datos sensibles (solo teléfono/ID, no CI ni email completo)
- [ ] `SHAREMEDATA_PATIENTS_URL` agregado a `.env.example`
