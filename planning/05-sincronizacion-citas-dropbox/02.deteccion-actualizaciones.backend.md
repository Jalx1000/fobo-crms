### Estado actual (insuficiente)

El comando extrae el `external_id` del nombre del archivo:

### Corrección

## Lógica de detección: nuevo vs. actualización

El comando `smd:sync-dropbox` necesita distinguir tres casos:

```
Caso 1: _id NO está en smd_synced_events  → CREAR (comportamiento actual)
Caso 2: _id SÍ está + payload cambió      → ACTUALIZAR
Caso 3: archived: true                    → CANCELAR / ARCHIVAR
```

### Estructura del método en el comando

```php
// SyncDropboxAppointments::handle() — lógica por archivo
$externalId = $json['_id'] ?? null;
$archived   = $json['archived'] ?? false;

$existing = DB::table('smd_synced_events')
    ->where('external_id', $externalId)
    ->first();

if ($archived) {
    // Caso 3: archivar/cancelar
    if ($existing) {
        $result = $this->incomingService->cancelDropbox($externalId, $existing);
        // actualizar registro
        DB::table('smd_synced_events')
            ->where('external_id', $externalId)
            ->update([
                'raw_payload' => json_encode($json),
                'archived_at' => now(),
                'updated_at'  => now(),
            ]);
    }
    continue;
}

if ($existing) {
    // Caso 2: actualizar si el payload cambió
    $existingHash = md5($existing->raw_payload ?? '');
    $newHash      = md5(json_encode($json));

    if ($existingHash === $newHash) {
        $skipped++;
        continue; // sin cambios, nada que hacer
    }

    $result = $this->incomingService->updateDropbox($json, $existing);

    DB::table('smd_synced_events')
        ->where('external_id', $externalId)
        ->update([
            'raw_payload' => json_encode($json),
            'updated_at'  => now(),
        ]);

    $updated++;
} else {
    // Caso 1: crear
    $result = $this->incomingService->processDropbox($json);

    DB::table('smd_synced_events')->insert([
        'external_id'  => $externalId,
        'source_file'  => $file['path_lower'],
        'source'       => 'dropbox',
        'activity_id'  => $result['activity_id'] ?? null,
        'lead_id'      => $result['lead_id']      ?? null,
        'raw_payload'  => json_encode($json),
        'processed_at' => now(),
        'created_at'   => now(),
        'updated_at'   => now(),
    ]);

    $processed++;
}
```

## Nuevo método: `updateDropbox()`

Agregar a `IncomingAppointmentService`:

```php
/**
 * Actualiza una cita existente en el CRM a partir de un JSON de Dropbox modificado.
 */
public function updateDropbox(array $data, object $existing): array
{
    $activityId = $existing->activity_id;
    $leadId     = $existing->lead_id;

    if (! $activityId) {
        // El registro existe en smd_synced_events pero no tiene activity_id
        // (pudo fallar la creación original). Intentar crear desde cero.
        Log::warning('[IncomingAppointment] update sin activity_id, creando nuevo', [
            'external_id' => $data['_id'],
        ]);
        return $this->processDropbox($data);
    }

    return DB::transaction(function () use ($data, $activityId, $leadId) {
        $normalized = $this->normalizeDropbox($data);

        // Actualizar Activity (fechas, título)
        $activity = $this->activityRepository->find($activityId);

        if ($activity) {
            $this->activityRepository->update([
                'title'         => $normalized['summary'] ?: $activity->title,
                'comment'       => $normalized['summary'] ?? $activity->comment,
                'schedule_from' => Carbon::parse($normalized['schedule_from'])->format('Y-m-d H:i:s'),
                'schedule_to'   => Carbon::parse($normalized['schedule_to'])->format('Y-m-d H:i:s'),
            ], $activityId);
        }

        // Actualizar Lead (título si cambió summary)
        if ($leadId && $normalized['summary']) {
            $this->leadRepository->update([
                'description' => $normalized['summary'],
            ], $leadId);
        }

        Log::info('[IncomingAppointment] Cita actualizada', [
            'external_id' => $data['_id'],
            'activity_id' => $activityId,
        ]);

        return ['lead_id' => $leadId, 'activity_id' => $activityId, 'action' => 'updated'];
    });
}
```

## Nuevo método: `cancelDropbox()`

```php
/**
 * Cancela/archiva una cita en el CRM cuando llega con archived: true desde SMD.
 */
public function cancelDropbox(string $externalId, object $existing): array
{
    $activityId = $existing->activity_id;
    $leadId     = $existing->lead_id;

    return DB::transaction(function () use ($externalId, $activityId, $leadId) {
        // Marcar Lead como perdido/cancelado
        if ($leadId) {
            // lead_stage_id para "Cancelado" — depende de la configuración del pipeline.
            // Ver Tarea 5.4 para el mapeo de estados.
            $cancelledStageId = config('smd.cancelled_lead_stage_id');

            if ($cancelledStageId) {
                $this->leadRepository->update([
                    'lead_stage_id' => $cancelledStageId,
                    'lost_reason'   => 'Cita cancelada/archivada en SMD',
                    'closed_at'     => now(),
                ], $leadId);
            }
        }

        Log::info('[IncomingAppointment] Cita archivada/cancelada desde SMD', [
            'external_id' => $externalId,
            'lead_id'     => $leadId,
            'activity_id' => $activityId,
        ]);

        return ['lead_id' => $leadId, 'activity_id' => $activityId, 'action' => 'cancelled'];
    });
}
```

## Refactor: extraer `normalizeDropbox()`

Para evitar duplicar la lógica de normalización entre `processDropbox()` y `updateDropbox()`, extraer a un método privado:

```php
/**
 * owner puede ser objeto O string (solo el _id).
 * Ej normal:    "owner": { "_id": "abc", "name": "Juan", "phone": "76123456" }
 * Ej cancelado: "owner": "69bd9a6a7549b10008e0ac6b"
 */
private function parseOwner(mixed $owner): array
{
    if (is_string($owner)) {
        return ['_id' => $owner, 'name' => null, 'lastName' => null, 'phone' => null];
    }
    if (is_array($owner)) {
        return [
            '_id'      => $owner['_id']      ?? null,
            'name'     => $owner['name']     ?? null,
            'lastName' => $owner['lastName'] ?? null,
            'phone'    => $owner['phone']    ?? null,
        ];
    }
    return ['_id' => null, 'name' => null, 'lastName' => null, 'phone' => null];
}

/**
 * attendances puede NO tener phone ni birthday (ej: eventos cancelados).
 * Búsqueda de paciente: phone → _id SMD → nombre completo.
 */
private function parseAttendance(array $attendance): array
{
    return [
        'name'       => $attendance['name']     ?? 'Paciente',
        'lastName'   => $attendance['lastName'] ?? '',
        'phone'      => $attendance['phone']    ?? null,   // puede ser null
        'birthday'   => $attendance['birthday'] ?? null,
        '_id'        => $attendance['_id']      ?? null,
    ];
}

private function normalizeDropbox(array $data): array
{
    // BUG FIX: el paciente ES el elemento del array, no una sub-clave 'patient'
    $rawPatient = $data['attendances'][0] ?? [];
    $patient    = $this->parseAttendance($rawPatient);
    $owner      = $this->parseOwner($data['owner'] ?? null);

    return [
        'doctor_external_id'  => $owner['_id'],
        'doctor_name'         => trim(($owner['name'] ?? '').' '.($owner['lastName'] ?? '')),
        'doctor_phone'        => $owner['phone'],
        'patient_name'        => trim($patient['name'].' '.$patient['lastName']),
        'patient_phone'       => $patient['phone'],       // null si no viene en el JSON
        'patient_external_id' => $patient['_id'],
        'patient_birthday'    => $patient['birthday'],
        'schedule_from'       => $data['startDate']  ?? null,
        'schedule_to'         => $data['endDate']    ?? null,
        'summary'             => $data['summary']    ?? '',   // → Activity.reason (motivo de consulta)
        'external_id'         => $data['_id']        ?? null,
        'archived'            => $data['archived']   ?? false,
        'status'              => $data['status']     ?? '',
    ];
}

public function processDropbox(array $data): array
{
    return $this->process($this->normalizeDropbox($data));
}
```
