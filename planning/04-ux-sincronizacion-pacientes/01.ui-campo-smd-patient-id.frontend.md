### Botón de sincronización (Vue inline)

```html
<div id="smd-sync-{{ $person->id }}">
    <v-smd-sync
        person-id="{{ $person->id }}"
        :initial-smd-id="{{ json_encode($person->smd_patient_id) }}"
        sync-url="{{ route('admin.contacts.persons.sync_smd', $person->id) }}"
    />
</div>

<script>
app.component('v-smd-sync', {
    props: ['personId', 'initialSmdId', 'syncUrl'],
    data() {
        return {
            smdId:   this.initialSmdId,
            loading: false,
            message: null,
            error:   null,
        };
    },
    template: `
        <div class="mt-2">
            <button
                v-if="!smdId"
                @click="syncPatient"
                :disabled="loading"
                class="inline-flex items-center gap-1.5 px-3 py-1.5 text-sm font-medium text-white bg-blue-600 rounded-md hover:bg-blue-700 disabled:opacity-50"
            >
                <span v-if="loading">Sincronizando...</span>
                <span v-else>Sincronizar con SMD</span>
            </button>

            <div v-if="message" class="mt-1 text-xs text-green-600">{{ message }}</div>
            <div v-if="error"   class="mt-1 text-xs text-red-600">{{ error }}</div>

            <div v-if="smdId" class="mt-1 text-xs text-gray-400 font-mono">
                ID SMD: {{ smdId }}
            </div>
        </div>
    `,
    methods: {
        async syncPatient() {
            this.loading = true;
            this.message = null;
            this.error   = null;

            try {
                const { data } = await this.$axios.post(this.syncUrl);
                this.smdId   = data.smd_patient_id;
                this.message = data.message || 'Sincronizado correctamente';
            } catch (err) {
                this.error = err.response?.data?.message || 'Error al sincronizar';
            } finally {
                this.loading = false;
            }
        },
    },
});
</script>
```

## Criterios de aceptación

- [ ] El badge verde "Sincronizado" se muestra si el paciente tiene `smd_patient_id`
- [ ] El badge amarillo "No sincronizado" se muestra si no tiene `smd_patient_id`
- [ ] El botón "Sincronizar con SMD" aparece solo si no está sincronizado
- [ ] Al clickear, muestra estado de carga "Sincronizando..."
- [ ] Al completar exitosamente, muestra el ID SMD y desaparece el botón
- [ ] Al fallar, muestra el mensaje de error en rojo
- [ ] No se rompe si `smd_patient_id` es null o si la API falla
