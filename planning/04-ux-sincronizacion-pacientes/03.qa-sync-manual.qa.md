# Tarea 4.3 — QA: Sincronización manual de paciente desde el panel

**Agente asignado:** `qa`
**Fase:** 04 — UX Sincronización de Pacientes
**Complejidad:** Baja
**Tiempo estimado:** 1h
**Dependencias:** Tarea 4.1 (UI), Tarea 4.2 (endpoint)

---

## Objetivo

Verificar que el flujo completo de sincronización manual de paciente funciona correctamente en la UI y persiste los datos.

## Casos de prueba

### Caso 1 — Paciente sin `smd_patient_id` → sincronización exitosa

**Pasos:**
1. Ir a un paciente que NO tiene `smd_patient_id` (badge amarillo visible)
2. Clickear "Sincronizar con SMD"
3. Observar el estado de carga
4. Verificar el resultado

**Resultado esperado:**
- Badge cambia de amarillo a verde
- Se muestra el ID SMD en texto gris pequeño
- El botón desaparece
- Al refrescar la página, el estado persiste (badge verde)

### Caso 2 — Paciente ya sincronizado

**Pasos:**
1. Ir a un paciente con `smd_patient_id` (badge verde)

**Resultado esperado:**
- No se muestra el botón "Sincronizar con SMD"
- Solo se muestra el badge verde con el ID

### Caso 3 — Paciente sin teléfono

**Pasos:**
1. Ir a un paciente sin `contact_numbers`
2. Clickear "Sincronizar con SMD"

**Resultado esperado:**
- Mensaje de error: "El paciente no tiene número de teléfono registrado"
- El badge no cambia

### Caso 4 — SMD no disponible

**Pasos:** Temporalmente setear `SHAREMEDATA_PATIENTS_URL` a una URL inválida y sincronizar

**Resultado esperado:**
- Mensaje de error visible en la UI: "No se pudo sincronizar con ShareMeData: ..."
- Ningún cambio en la BD

### Caso 5 — Test automatizado

Crear `tests/Feature/PersonSmdSyncTest.php`:

```php
uses(DatabaseTransactions::class);

it('sincroniza paciente existente en SMD y guarda smd_patient_id', function () {
    Http::fake([
        '*/patients*' => Http::response(['data' => [['_id' => 'smd-test-123']]], 200),
    ]);

    $person = Person::create([
        'name'            => 'Test Sync ' . uniqid(),
        'contact_numbers' => [['value' => '77700001', 'label' => 'work']],
    ]);

    actingAs(User::find(1), 'user')
        ->postJson(route('admin.contacts.persons.sync_smd', $person->id))
        ->assertStatus(200)
        ->assertJsonFragment(['smd_patient_id' => 'smd-test-123']);

    expect($person->fresh()->smd_patient_id)->toBe('smd-test-123');
});

it('retorna 422 si el paciente no tiene teléfono', function () {
    $person = Person::create(['name' => 'Sin Tel ' . uniqid()]);

    actingAs(User::find(1), 'user')
        ->postJson(route('admin.contacts.persons.sync_smd', $person->id))
        ->assertStatus(422)
        ->assertJsonFragment(['message' => 'El paciente no tiene número de teléfono registrado.']);
});
```

## Criterios de aceptación

- [ ] UI muestra correctamente los dos estados (sincronizado / no sincronizado)
- [ ] La sincronización exitosa actualiza la UI sin recargar la página
- [ ] Los errores se muestran en la UI de forma legible
- [ ] `php artisan test tests/Feature/PersonSmdSyncTest.php` pasa en verde
- [ ] El `smd_patient_id` persiste en la BD tras sincronizar
