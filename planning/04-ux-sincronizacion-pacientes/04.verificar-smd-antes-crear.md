# Tarea 4.4 — Verificar paciente en SMD antes de crear

**Fase:** 04 — UX Sincronización de Pacientes  
**Complejidad:** Media  
**Tiempo estimado:** 3h  
**Dependencias:** searchPatient, searchPatientByEmail (ya implementados)

---

## Objetivo

Agregar un buscador en el formulario de **creación de paciente** que permite verificar si el paciente ya existe en SMD antes de guardar. Si existe, auto-completa el formulario con sus datos. Si no existe, muestra "No encontrado" y permite continuar con la creación normal.

---

## Decisión UX

**Patrón elegido: buscador único al tope del formulario**

Un solo campo de búsqueda acepta teléfono, CI o email (el sistema prueba los 3 en orden). Razones:
- Evita 3 botones dispersos en el formulario
- Flujo lineal: buscar → verificar → completar → guardar
- Patrón estándar de deduplicación en CRMs

---

### Endpoint `searchSmd()` en PersonController

```php
public function searchSmd(Request $request): JsonResponse
{
    $term = trim($request->get('q', ''));

    if (strlen($term) < 3) {
        return response()->json(['found' => false, 'message' => 'Ingresa al menos 3 caracteres.']);
    }

    // 1. Buscar por teléfono
    $results = $this->shareMeDataService->searchPatient($term);

    // 2. Buscar por email
    if (empty($results)) {
        $results = $this->shareMeDataService->searchPatientByEmail($term);
    }

    // 3. Buscar por CI (personID)
    if (empty($results)) {
        $results = $this->shareMeDataService->searchPatientByCi($term);
    }

    if (empty($results)) {
        return response()->json(['found' => false]);
    }

    $patient = $results[0];

    return response()->json([
        'found'      => true,
        'smd_id'     => $patient['_id']      ?? null,
        'name'       => trim(($patient['name'] ?? '') . ' ' . ($patient['lastName'] ?? '')),
        'phone'      => $patient['phone']     ?? null,
        'ci'         => $patient['personID']  ?? null,
        'email'      => $patient['secondEmail'] ?? null,
        'birthday'   => $patient['birthday']  ?? null,
        'insurance'  => $patient['extra']['insurance'][0] ?? null,
    ]);
}
```

### Nuevo método en ShareMeDataService

```php
public function searchPatientByCi(string $ci): array
{
    try {
        $response = $this->http()->get("{$this->patientsBaseUrl}/patients", [
            'where'      => 'personID=/'.urlencode($ci).'/',
            'select'     => '_id,fullName,phone,secondEmail,name,lastName,personID,birthday,extra',
            'pageSize'   => 5,
            'pageNumber' => 1,
        ]);

        return $response->successful()
            ? ($response->json('data') ?? $response->json() ?? [])
            : [];
    } catch (\Exception $e) {
        Log::error('[SMD] searchPatientByCi excepción: ' . $e->getMessage());
        return [];
    }
}
```

### Componente Vue en create.blade.php

```html
{{-- Bloque de verificación SMD al inicio del formulario --}}
<div class="mb-6 rounded-lg border border-blue-200 bg-blue-50 p-4 dark:border-blue-800 dark:bg-blue-900/20">
    <p class="mb-2 text-sm font-medium text-blue-700 dark:text-blue-300">
        Verificar si el paciente existe en ShareMeData
    </p>

    <v-smd-search
        search-url="{{ route('admin.contacts.persons.search_smd') }}"
    />
</div>

@push('scripts')
<script>
app.component('v-smd-search', {
    props: ['searchUrl'],
    data() {
        return {
            query:   '',
            loading: false,
            result:  null,   // null | { found: false } | { found: true, ...datos }
        };
    },
    template: `
        <div>
            <div class="flex gap-2">
                <input
                    v-model="query"
                    type="text"
                    placeholder="Teléfono, CI o email..."
                    class="flex-1 rounded-md border border-blue-300 px-3 py-1.5 text-sm focus:border-blue-500 focus:outline-none dark:border-blue-700 dark:bg-gray-800"
                    @keyup.enter="search"
                />
                <button
                    type="button"
                    @click="search"
                    :disabled="loading || query.length < 3"
                    class="inline-flex items-center gap-1.5 rounded-md bg-blue-600 px-3 py-1.5 text-sm font-medium text-white hover:bg-blue-700 disabled:opacity-50"
                >
                    <span v-if="loading">Buscando...</span>
                    <span v-else>Verificar</span>
                </button>
            </div>

            <!-- No encontrado -->
            <p v-if="result && !result.found" class="mt-2 text-sm text-yellow-600">
                ⚠️ Paciente no encontrado en SMD. Complete el formulario para crearlo.
            </p>

            <!-- Encontrado -->
            <div v-if="result && result.found" class="mt-3 rounded-md border border-green-300 bg-white p-3 dark:bg-gray-800">
                <p class="mb-1 text-xs font-semibold text-green-700">✅ Paciente encontrado en SMD</p>
                <div class="grid grid-cols-2 gap-x-4 text-sm text-gray-700 dark:text-gray-300">
                    <span class="font-medium">Nombre:</span>  <span>@{{ result.name }}</span>
                    <span class="font-medium">Teléfono:</span><span>@{{ result.phone || '—' }}</span>
                    <span class="font-medium">CI:</span>      <span>@{{ result.ci || '—' }}</span>
                    <span class="font-medium">Email:</span>   <span>@{{ result.email || '—' }}</span>
                    <span v-if="result.insurance" class="font-medium">Seguro:</span>
                    <span v-if="result.insurance">@{{ result.insurance }}</span>
                </div>
                <button
                    type="button"
                    @click="fillForm"
                    class="mt-2 text-sm font-medium text-blue-600 hover:underline"
                >
                    ↓ Usar estos datos
                </button>
            </div>
        </div>
    `,
    methods: {
        async search() {
            if (this.query.length < 3) return;
            this.loading = true;
            this.result  = null;
            try {
                const { data } = await this.$axios.get(this.searchUrl, { params: { q: this.query } });
                this.result = data;
            } catch {
                this.result = { found: false };
            } finally {
                this.loading = false;
            }
        },

        fillForm() {
            if (! this.result?.found) return;

            // Completar campos del formulario por name attribute
            const set = (name, val) => {
                if (! val) return;
                const el = document.querySelector(`[name="${name}"]`);
                if (el) {
                    el.value = val;
                    el.dispatchEvent(new Event('input', { bubbles: true }));
                }
            };

            // Dividir nombre en partes
            const parts = (this.result.name || '').trim().split(' ');
            set('name', this.result.name);
            set('ci_paciente', this.result.ci);
            set('job_title', '');  // edad se limpia, no viene de SMD

            // Teléfono: el formulario usa contact_numbers[]
            if (this.result.phone) {
                // Emitir evento global para que el componente de teléfonos lo reciba
                this.$emitter.emit('smd:fill-phone', this.result.phone);
            }
        },
    },
});
</script>
@endpush
```
