# Tarea 8.6 — Tests Pest completos para `GET /api/v1/insurance/verify`

**Agente asignado:** `tester`
**Fase:** 08 — Agente WhatsApp

## Objetivo

Crear tests Pest que cubran el endpoint `GET /api/v1/insurance/verify` incluyendo: autenticación, validación, respuestas correctas, rate limiting y escritura del audit log.

## Contexto

- El endpoint usa `InsuranceService::verifyWithParams()` que llama a drivers externos (Alianza, Nacional Vida, etc.) via HTTP. En tests se mockean con `Http::fake()`.
- La tabla `insurance_audit_logs` se escribe en cada request (Tarea 8.5).
- Rate limit: 10 req/min por token (Tarea 8.5).
- Ver `tests/Feature/InsuranceVerificationTest.php` para patrones de test de seguros existentes.
- Ver `tests/Feature/DoctorApiTest.php` para patrones de fixture con `DatabaseTransactions`.

**Estructura de respuesta positiva (Tarea 8.4):**
```json
{
  "has_insurance": true,
  "insurance_name": "...",
  "policy_number": null,
  "coverage_type": "dental",
  "valid_until": null,
  "covered_services": [],
  "patient_name": "...",
  "patient_id": 55
}
```

**Estructura de respuesta negativa (anti-enumeración):**
```json
{ "has_insurance": false, "patient_found": false }
```

## Archivos a crear / modificar

### Crear
- `tests/Feature/AgentInsuranceVerifyTest.php`

## Implementación

Archivo: `tests/Feature/AgentInsuranceVerifyTest.php`

```php
<?php

use Illuminate\Foundation\Testing\DatabaseTransactions;
use Illuminate\Support\Facades\Http;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\RateLimiter;
use Webkul\Contact\Models\Person;
use Webkul\User\Models\User;
use Webkul\Attribute\Models\Attribute;
use function Pest\Laravel\get;

uses(DatabaseTransactions::class);

// ─── Fixtures ──────────────────────────────────────────────────────────────

beforeEach(function () {
    $this->user = User::find(1);

    // Asegurar que exista el atributo ci_paciente
    $this->ciAttr = Attribute::where('code', 'ci_paciente')->first()
        ?? Attribute::create([
            'code'        => 'ci_paciente',
            'name'        => 'CI Paciente',
            'type'        => 'text',
            'entity_type' => 'persons',
            'admin_name'  => 'CI Paciente',
        ]);

    // Crear paciente de prueba con CI en attribute_values
    $this->testCi = 'TEST-CI-' . uniqid();
    $this->person = Person::create(['name' => 'Paciente Test ' . uniqid()]);

    DB::table('attribute_values')->insert([
        'entity_type'  => 'persons',
        'entity_id'    => $this->person->id,
        'attribute_id' => $this->ciAttr->id,
        'text_value'   => $this->testCi,
    ]);

    // Limpiar rate limiter para evitar interferencia entre tests
    RateLimiter::clear('insurance-agent|' . $this->user->currentAccessToken()?->id);
});

// ─── Autenticación ─────────────────────────────────────────────────────────

it('devuelve 401 sin token', function () {
    get('/api/v1/insurance/verify?ci_paciente=12345678&seguro_paciente=Alianza')
        ->assertStatus(401);
});

it('devuelve 422 si falta ci_paciente', function () {
    $this->actingAs($this->user, 'sanctum')
        ->get('/api/v1/insurance/verify?seguro_paciente=Alianza')
        ->assertStatus(422)
        ->assertJsonValidationErrors(['ci_paciente']);
});

it('devuelve 422 si falta seguro_paciente', function () {
    $this->actingAs($this->user, 'sanctum')
        ->get('/api/v1/insurance/verify?ci_paciente=12345678')
        ->assertStatus(422)
        ->assertJsonValidationErrors(['seguro_paciente']);
});

it('devuelve 422 si ci_paciente tiene menos de 3 caracteres', function () {
    $this->actingAs($this->user, 'sanctum')
        ->get('/api/v1/insurance/verify?ci_paciente=12&seguro_paciente=Alianza')
        ->assertStatus(422)
        ->assertJsonValidationErrors(['ci_paciente']);
});

// ─── Respuesta negativa (anti-enumeración) ─────────────────────────────────

it('devuelve has_insurance:false cuando el CI no existe en la BD', function () {
    Http::fake(); // No debería llamar a drivers externos

    $this->actingAs($this->user, 'sanctum')
        ->get('/api/v1/insurance/verify?ci_paciente=CI-INEXISTENTE-999&seguro_paciente=Alianza')
        ->assertStatus(200)
        ->assertExactJson([
            'has_insurance' => false,
            'patient_found' => false,
        ]);
});

it('devuelve has_insurance:false cuando el seguro no está activo (VENCIDO)', function () {
    Http::fake([
        '*' => Http::response([
            'success' => true,
            'data'    => [['ESTADO' => 'VENCIDO', 'NOMBRE COMPLETO' => 'Paciente Test']],
        ], 200),
    ]);

    $this->actingAs($this->user, 'sanctum')
        ->get("/api/v1/insurance/verify?ci_paciente={$this->testCi}&seguro_paciente=Alianza")
        ->assertStatus(200)
        ->assertExactJson([
            'has_insurance' => false,
            'patient_found' => false,
        ]);
});

it('devuelve has_insurance:false cuando el seguro no está activo (NO_REGISTRADO)', function () {
    Http::fake([
        '*' => Http::response([
            'success' => false,
            'data'    => [],
        ], 200),
    ]);

    $this->actingAs($this->user, 'sanctum')
        ->get("/api/v1/insurance/verify?ci_paciente={$this->testCi}&seguro_paciente=Alianza")
        ->assertStatus(200)
        ->assertExactJson([
            'has_insurance' => false,
            'patient_found' => false,
        ]);
});

it('la respuesta negativa NO incluye patient_id (anti-enumeración)', function () {
    Http::fake([
        '*' => Http::response(['success' => false, 'data' => []], 200),
    ]);

    $response = $this->actingAs($this->user, 'sanctum')
        ->get("/api/v1/insurance/verify?ci_paciente={$this->testCi}&seguro_paciente=Alianza")
        ->assertStatus(200);

    expect($response->json())->not->toHaveKey('patient_id');
    expect($response->json())->not->toHaveKey('patient_name');
});

// ─── Respuesta positiva ─────────────────────────────────────────────────────

it('devuelve has_insurance:true cuando el seguro está VIGENTE', function () {
    Http::fake([
        '*' => Http::response([
            'success' => true,
            'data'    => [[
                'ESTADO'          => 'VIGENTE',
                'NOMBRE COMPLETO' => $this->person->name,
                'VIGENCIA HASTA'  => '31/12/2026',
            ]],
        ], 200),
    ]);

    $response = $this->actingAs($this->user, 'sanctum')
        ->get("/api/v1/insurance/verify?ci_paciente={$this->testCi}&seguro_paciente=Alianza")
        ->assertStatus(200);

    expect($response->json('has_insurance'))->toBeTrue();
    expect($response->json('patient_id'))->toBe($this->person->id);
    expect($response->json('patient_name'))->toBe($this->person->name);
});

it('devuelve has_insurance:true cuando el seguro está EN_MORA', function () {
    Http::fake([
        '*' => Http::response([
            'success' => true,
            'data'    => [['ESTADO' => 'EN_MORA', 'NOMBRE COMPLETO' => 'Paciente Mora']],
        ], 200),
    ]);

    $response = $this->actingAs($this->user, 'sanctum')
        ->get("/api/v1/insurance/verify?ci_paciente={$this->testCi}&seguro_paciente=Alianza")
        ->assertStatus(200);

    expect($response->json('has_insurance'))->toBeTrue();
});

it('la respuesta positiva tiene la estructura correcta', function () {
    Http::fake([
        '*' => Http::response([
            'success' => true,
            'data'    => [['ESTADO' => 'VIGENTE', 'NOMBRE COMPLETO' => 'Test']],
        ], 200),
    ]);

    $this->actingAs($this->user, 'sanctum')
        ->get("/api/v1/insurance/verify?ci_paciente={$this->testCi}&seguro_paciente=Alianza")
        ->assertStatus(200)
        ->assertJsonStructure([
            'has_insurance',
            'insurance_name',
            'policy_number',
            'coverage_type',
            'valid_until',
            'covered_services',
            'patient_name',
            'patient_id',
        ]);
});

// ─── Rate Limiting ─────────────────────────────────────────────────────────

it('devuelve 429 después de 10 requests por minuto', function () {
    Http::fake([
        '*' => Http::response(['success' => false, 'data' => []], 200),
    ]);

    // Los primeros 10 deben pasar
    for ($i = 1; $i <= 10; $i++) {
        $this->actingAs($this->user, 'sanctum')
            ->get("/api/v1/insurance/verify?ci_paciente=CI-{$i}&seguro_paciente=Alianza")
            ->assertStatus(200);
    }

    // El request #11 debe ser bloqueado
    $this->actingAs($this->user, 'sanctum')
        ->get('/api/v1/insurance/verify?ci_paciente=CI-11&seguro_paciente=Alianza')
        ->assertStatus(429)
        ->assertJson(['message' => 'Too many requests. Maximum 10 verifications per minute per token.']);
});

// ─── Audit Log ─────────────────────────────────────────────────────────────

it('escribe una fila en insurance_audit_logs por cada request', function () {
    Http::fake([
        '*' => Http::response(['success' => false, 'data' => []], 200),
    ]);

    $countBefore = DB::table('insurance_audit_logs')->count();

    $this->actingAs($this->user, 'sanctum')
        ->get("/api/v1/insurance/verify?ci_paciente={$this->testCi}&seguro_paciente=Alianza");

    expect(DB::table('insurance_audit_logs')->count())->toBe($countBefore + 1);
});

it('el audit log guarda result:false cuando has_insurance es false', function () {
    Http::fake([
        '*' => Http::response(['success' => false, 'data' => []], 200),
    ]);

    $this->actingAs($this->user, 'sanctum')
        ->get("/api/v1/insurance/verify?ci_paciente={$this->testCi}&seguro_paciente=Alianza");

    $log = DB::table('insurance_audit_logs')->latest('id')->first();
    expect((bool) $log->result)->toBeFalse();
});

it('el audit log guarda result:true cuando has_insurance es true', function () {
    Http::fake([
        '*' => Http::response([
            'success' => true,
            'data'    => [['ESTADO' => 'VIGENTE', 'NOMBRE COMPLETO' => 'Test']],
        ], 200),
    ]);

    $this->actingAs($this->user, 'sanctum')
        ->get("/api/v1/insurance/verify?ci_paciente={$this->testCi}&seguro_paciente=Alianza");

    $log = DB::table('insurance_audit_logs')->latest('id')->first();
    expect((bool) $log->result)->toBeTrue();
});

it('el audit log NO guarda el CI en claro', function () {
    Http::fake([
        '*' => Http::response(['success' => false, 'data' => []], 200),
    ]);

    $this->actingAs($this->user, 'sanctum')
        ->get("/api/v1/insurance/verify?ci_paciente={$this->testCi}&seguro_paciente=Alianza");

    $log = DB::table('insurance_audit_logs')->latest('id')->first();

    // El ci_hash debe ser SHA-256 (64 chars hex), no el CI en claro
    expect($log->ci_hash)->toHaveLength(64);
    expect($log->ci_hash)->not->toBe($this->testCi);
    // Verificar que es el hash correcto del CI
    expect($log->ci_hash)->toBe(hash('sha256', $this->testCi));
});

it('el audit log NO guarda el token en claro', function () {
    Http::fake([
        '*' => Http::response(['success' => false, 'data' => []], 200),
    ]);

    $this->actingAs($this->user, 'sanctum')
        ->get("/api/v1/insurance/verify?ci_paciente={$this->testCi}&seguro_paciente=Alianza");

    $log = DB::table('insurance_audit_logs')->latest('id')->first();

    // El token_hash debe tener 64 chars (SHA-256 hex)
    expect($log->token_hash)->toHaveLength(64);
});

it('escribe audit log incluso cuando falla el driver externo (502)', function () {
    Http::fake([
        '*' => Http::response([], 500),
    ]);

    $countBefore = DB::table('insurance_audit_logs')->count();

    $this->actingAs($this->user, 'sanctum')
        ->get("/api/v1/insurance/verify?ci_paciente={$this->testCi}&seguro_paciente=Alianza");

    // Debe escribir audit log independientemente del resultado del driver
    expect(DB::table('insurance_audit_logs')->count())->toBeGreaterThan($countBefore);
});
```

## Criterios de aceptación

- [ ] `php artisan test tests/Feature/AgentInsuranceVerifyTest.php` pasa todos los tests (verde)
- [ ] Los tests de anti-enumeración fallan si el controlador devuelve `patient_found: true` cuando el paciente existe
- [ ] Los tests de rate limit fallan si el throttle está configurado a más de 10 req/min
- [ ] Los tests de audit log fallan si el CI se guarda en claro
- [ ] Ningún test depende de datos fijos de la BD (todos usan `uniqid()` para el CI de prueba)
- [ ] Los tests limpian el rate limiter en `beforeEach` para evitar interferencias entre tests
