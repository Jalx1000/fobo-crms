# Tarea 8.2 — Agregar `duration_minutes` a productos: migración + API + formulario

**Agente asignado:** `backend`
**Fase:** 08 — Agente WhatsApp
**Complejidad:** Media
**Tiempo estimado:** 2h
**Dependencias:** Ninguna

---

## Objetivo

Añadir el campo `duration_minutes` (integer, nullable) a la tabla `products` para que el agente de WhatsApp sepa cuántos minutos dura cada servicio dental. La API devuelve `null` cuando no está configurado (el default de 60 min lo aplica el agente, no el CRM).

## Contexto

El agente actualmente asume 60 minutos para todos los servicios porque no hay campo de duración. Esto provoca que los slots de disponibilidad calculados sean incorrectos para procedimientos más cortos (limpieza: 30 min) o más largos (implante: 120 min).

**Estado actual del modelo:**

- `packages/Webkul/Product/src/Models/Product.php` — `$fillable = ['name', 'sku', 'description', 'quantity', 'price']`
- `packages/Webkul/Product/src/Database/Migrations/2021_04_09_065617_create_products_table.php` — tabla `products` con columnas: `id`, `sku`, `name`, `description`, `quantity`, `price`, `timestamps`
- `routes/api.php` líneas 26-69 — `GET /api/public/products` devuelve productos con sus atributos custom pero no `duration_minutes` (no es custom attribute, es columna directa)

## Archivos a crear / modificar

### Crear
- `packages/Webkul/Product/src/Database/Migrations/2026_05_24_000001_add_duration_minutes_to_products_table.php`

### Modificar

- `routes/api.php` — añadir `duration_minutes` al map de `GET /api/public/products`

### 3. Endpoint `GET /api/public/products`

Archivo: `routes/api.php`

El endpoint actual en las líneas ~56-67 hace un `$product->attributesToArray()` y luego itera custom attributes. La columna `duration_minutes` es una columna directa, no un custom attribute, por lo que se incluye en `attributesToArray()` automáticamente cuando está en `$fillable`.

**Verificar** que la respuesta incluya el campo ejecutando:

```bash
curl -s "http://localhost/api/public/products" | jq '.[0].data[0].duration_minutes'
```

Si `attributesToArray()` no lo incluye (por ser `$fillable` no `$attributes`), añadir explícitamente en el `map`:

```php
// En el closure del map() en routes/api.php (línea ~56):
$products = $query->orderBy('created_at', 'desc')->get()->map(function ($product) use ($valueRepo) {
    $data = $product->attributesToArray();

    // Campos directos que no son custom attributes:
    $data['duration_minutes'] = $product->duration_minutes; // null si no está seteado

    foreach ($product->getCustomAttributes() as $attribute) {
        $raw = $product->getCustomAttributeValue($attribute);
        $data[$attribute->code] = $attribute->type === 'boolean'
            ? $raw
            : $valueRepo->getAttributeLabel($raw, $attribute);
    }

    return $data;
});
```
